# AWARE: Automated LEO SGP4 Empirical Sensitivity Engine

Automated astrodynamics pipeline for empirical sensitivity limits and ephemeris degradation thresholds of SGP4 in upper Low Earth Orbit during the May 2024 G5 geomagnetic superstorm (*Dst* = −412 nT, *Kp* = 9.0).

Companion repository providing open-source replication code and radar-derived telemetry analysis for:  
**"Empirical Sensitivity Limits and Ephemeris Degradation Thresholds of SGP4 in Upper Low Earth Orbit During the May 2024 G5 Superstorm"** (Farhan Mahmood Saad Sarker, 2026).
